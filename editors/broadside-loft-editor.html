Broadside Ship Loft Editor — Documentation

A browser tool for designing capital-ship sprites. You shape a low-poly hull by editing two 2D profiles; it lofts them into 3D and renders the result as crisp ¾-view pixel art you can export as PNGs for the game.

1 · The core idea — lofting

The hull is built by lofting: a cross-section shape is swept along a length, scaled at each point by a width outline. Two editors drive this:

  • Plan view — the top-down hull outline. Each point sets the hull's half-width at a position along its length (prow at right, stern at left).
  • Section view — the cross-section ring shape (dorsal deck on top, chine at the widest, belly below). This profile is reused at every station, scaled to the plan width.

Together they define the whole hull. Superstructure, engines, guns and greebles are layered on top automatically.

2 · Editing the profiles

  • Drag a point to move it. The 3D preview updates live.
  • Add a point: switch to the add tool and click, or double-click an edge.
  • Delete a point: right-click it (a minimum of 3 points is kept).
  • Reset dagger / reset restores the default Star Destroyer profiles.

3 · Importing a side view

The ⤒ import side view button (plan editor toolbar) loads a PNG/JPG/WebP and does two things:

  • Auto-trace → height profile. The image's silhouette is scanned column by column; the vertical extent at each column becomes the hull's height along its length. A tall midsection bulges the hull there; a shallow nose makes the prow thin.
  • Faded underlay. The image sits at ~32% opacity behind the plan grid so you can trace the width outline over it by hand.

Important limits. A single side view only contains height + length information — it cannot tell the tool how wide the ship is or what its cross-section looks like. So import sets the height profile and gives you a tracing guide, but you still supply width (plan points) and shape (section editor) yourself. For best tracing: prow pointing right, on a clean transparent or solid-contrast background (the tracer reads the background color from the top-left corner). Use clear image to remove the underlay and traced profile.

4 · Shaping a capital ship

What makes a hull read as a capital ship rather than a fighter:

  • Length stretch high (≈2.5–3×) and height scale low (≈0.5×) for the long, shallow wedge.
  • Greeble density up — this scatters hull-scaled panel/window detail and increases the broadside battery count. Small detail against a big hull is the single strongest scale cue.
  • Superstructure on — adds the stepped command tower, bridge and sensor domes near the stern.

5 · View & lighting

  • Drag the preview to orbit; scroll to zoom.
  • Snap buttons jump to the four canonical stances: right / left (bow-on) and fore / aft (broadside).
  • ¾ pitch sets the look-down angle. Light azimuth / elevation steer the key light to bring out hull facets.

6 · Color & palette

  • Palette bands posterizes the render into 2–5 flat tones (or full) for a limited-palette pixel look.
  • Hue / saturation / brightness / contrast / gamma grade the color before banding. Reset grade returns to neutral.
  • Background picker + presets (white / grey / dark / blue) change the stage behind the ship. The exported sprite keeps a transparent background regardless.

7 · Exporting PNGs

  • Export scale 1× gives native sprite resolution; 2–8× nearest-neighbor upscales (stays crisp).
  • ⤓ PNG (this angle) saves the current view with pitch, palette and grade baked in, transparent background.
  • ⤓ right · left · fore · aft rotates through all four stances and saves each. Your browser may ask to allow multiple downloads the first time.
  • Render res (120–480) sets the sprite's native pixel size.

8 · Roadmap / not yet built

  • Free-form vertex editing (move individual 3D points, beyond the two profiles).
  • Saving/loading hull designs (profiles + settings) as a file.
  • Import orientation toggle (prow-left vs prow-right) and inverted-silhouette handling.
  • Sprite-sheet export (all four views packed into one PNG).

9 · Hosting it for two people

This is a single self-contained HTML file (it only pulls Three.js from a CDN), so it runs by just opening the file — but to share it on your home network so you and your son can both reach it from any device, run a tiny local web server on one machine:

cd folder-with-the-file
python3 -m http.server 8000

Then on that machine open http://localhost:8000/broadside-loft-editor.html, and from any other device on the same Wi-Fi open http://<that-machine's-LAN-IP>:8000/broadside-loft-editor.html (find the IP with ipconfig on Windows or ifconfig/ip addr on Mac/Linux — it usually looks like 192.168.x.x).
